# PAVE Sync Docs

Before acting:
1. Read applicable repository instructions.
2. Read `../../commands/sync-docs.md`,
   `../pave/references/memory.md`, and
   `../pave/references/verification.md`.
3. Read `../pave/references/context-retrieval.md` only when the requested

   `../pave/references/history-backfill.md` and
   `../pave/references/git.md`.

Then follow the command file. Do not invent decisions or create a parallel
documentation tree.
