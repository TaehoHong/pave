# PAVE Plan

Use this as the discoverable Codex entrypoint for `$pave:plan`.

Before acting:
1. Read `../pave/references/planning.md` and
   `../pave/references/testing.md`.
2. When the request states a behavior-changing outcome without
   implementation-ready requirements, or a material user-owned decision is
   unresolved, also read `../pave/references/design.md`.
3. Read applicable repository instructions and the smallest relevant docs,
   source files, and tests.

Produce the requested plan. Do not edit code or tests.
